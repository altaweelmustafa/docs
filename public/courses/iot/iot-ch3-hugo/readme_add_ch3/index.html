Add IoT Chapter 3 to the Hugo site

This pack adds Chapter 3: IoT as Interconnection of Threats up to slide 40, ending at Attacks as per architecture.

1) Copy the chapter folder

From your Hugo project root:

cp -r content/docs/courses/iot/ch3 YOUR_HUGO_PROJECT/content/docs/courses/iot/

If you unzip this pack inside the Hugo project root, you can just keep the content/docs/courses/iot/ch3/ folder where it is.

2) Add the Chapter 3 link to the IoT Security page

Open:

content/docs/courses/iot/_index.md

Add this after Chapter 2:

[Chapter 3: IoT as Interconnection of Threats](ch3/)

IoT phases, phase-based threats, availability attacks, data modification, eavesdropping, privilege escalation, brute-force attacks, and architecture-based attacks up to slide 40.

3) Run locally

hugo server -D

Open:

http://localhost:1313/docs/courses/iot/ch3/

Operating Systems

Operating Systems COMP431 - Birzeit University

Chapter 1: Introduction to Operating Systems

OS goals, computer system structure, OS views, history of batch systems, buffering, spooling, multiprogramming, timesharing, parallel and real-time systems.

Chapter 2: Computer System Operations

Device controllers, interrupts, I/O types, DMA, primary and secondary storage, cache memory, dual-mode operation, and hardware protection.

Chapter 3: Process Management

Process concept, memory layout, process states, PCB, scheduling queues, process creation and termination, cooperating processes, and the producer-consumer problem.

Chapter 4: Threads

Thread concept, heavyweight vs lightweight processes, user-level and kernel-level threads, and the three threading models.

Chapter 5: CPU Scheduling

CPU scheduling criteria, preemptive vs non-preemptive scheduling, and all six algorithms: FCFS, SJF, Priority, Round Robin, Multi-Level Queues, and Multi-Level Feedback Queues.

Chapter 6: Concurrent Processes & Process Synchronization

Precedence graphs, Bernstein's conditions, Fork/Join, Parbegin/Parend, the Critical Section Problem, software and hardware solutions, semaphores, and the classical synchronization problems.

Chapter 7: Deadlocks

Deadlock definition, system model, the four necessary conditions, resource allocation graphs, deadlock prevention, and deadlock avoidance with the Banker's Algorithm.

Chapter 8: Memory Management

Ordinary memory management, logical vs physical addresses, binding times, contiguous and non-contiguous allocation, paging, segmentation, and multi-level page tables.

Chapter 9: Virtual Memory Management

Demand paging, valid/invalid bits, page faults, page replacement algorithms (FIFO, Optimal, LRU, Second Chance), frame allocation strategies, and thrashing.

Chapter 10: Disk Scheduling

Hard disk structure, access time components, and disk scheduling algorithms: FCFS, SSTF, SCAN, C-SCAN, LOOK, and C-LOOK.

Chapter 11+12: File System

File access methods, the device directory, and disk space allocation methods: contiguous, linked, and indexed allocation.

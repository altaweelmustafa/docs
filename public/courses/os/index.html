Operating Systems

Operating Systems COMP431 - Birzeit University

Chapter 1: Introduction to Operating Systems

OS goals, computer system structure, OS views, history of batch systems, buffering, spooling, multiprogramming, timesharing, parallel and real-time systems.

Chapter 2: Computer System Operations

Device controllers, interrupts, I/O types, DMA, primary and secondary storage, cache memory, dual-mode operation, and hardware protection.

Chapter 3: Process Management

Process concept, memory layout, process states, PCB, scheduling queues, process creation and termination, cooperating processes, and the producer-consumer problem.

Chapter 4: Threads

Thread concept, heavyweight vs lightweight processes, user-level and kernel-level threads, and the three threading models.

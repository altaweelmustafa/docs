Chapter 3, Part 3 – Programming Languages Domains

posted on 2026 Jun 19

Contents

Programming languages are generally split into several domains based on their use case.

Domain Description Example Languages
Scientific Applications with a computational base. Where programming originally started. FORTRAN, C, ALGOL60
Business Applications for commercial use, especially banking. Came after the scientific domain. COBOL (and database languages), JAVA
Artificial Intelligence Languages built for AI work LISP, PROLOG
Systems Programming Programming all aspects of the computer, including hardware Machine Language, Assembly, C
Very High Level Languages Essentially scripting languages Python, Bash

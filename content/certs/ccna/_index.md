## Exam blueprint (v1.1)

| Domain | Weight |
|---|---:|
| 1.0 Network Fundamentals | 20% |
| 2.0 Network Access | 20% |
| 3.0 IP Connectivity | 25% |
| 4.0 IP Services | 10% |
| 5.0 Security Fundamentals | 15% |
| 6.0 Automation and Programmability | 10% |

These notes skip the beginner explanations (OSI in general, what a router does, etc.) since you already know Cisco networking. They focus on the numbers, defaults, and comparisons the exam actually tests: timers, administrative distances, port numbers, ACL ranges, wildcard masks, protocol comparisons.
